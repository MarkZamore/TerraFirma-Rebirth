# Управление TerraFirma Rebirth

`launcher/controls-preset.txt` содержит полную раскладку: **213 назначений, 86 включённых и 127 снятых**. Все включённые используют разные физические клавиши. Проверка не допускает пересечений, сочетаний Shift/Ctrl/Alt, повторов или пропущенных зарегистрированных назначений. Цифровой блок и дополнительные функциональные клавиши F13–F25 не нужны.

Это публичные данные сборки. После изменения, добавления или удаления файла и публикации GitHub release лаунчер получает новую доступность пресета из источника сборки. Настройки игрока меняются только после нажатия кнопки применения. Пресет не переносит видео, звук, язык, чувствительность мыши или настройки мира.

## Источники

210 назначений проверены по `options.txt` запускавшегося инстанса TerraFirma Rebirth. Список совпадает с сохранённым в сборке `configureddefaults/options.txt`; этот переносимый файл используется как воспроизводимый снимок регистрации, а не как готовая бесконфликтная раскладка. Сканер дополнительно читает 200 настоящих jar сборки: переводы имён, конструкторы KeyMapping и контексты NeoForge. Из jar найдены ещё три назначения: `key.aero_cam_sync.add_mainhand_item_client`, `key.jei.internal.enter.key` и `key.oelib.open_fluid_example`. Все они явно сняты: первое является служебной настройкой, второе дублирует навигацию JEI, третье открывает пример библиотеки.

Контексты получены из байткода для 9 назначений; остальные считаются `UNIVERSAL` консервативно. Никаких ослабляющих исключений нет: `contexts.overrides.json` и `allowed-conflicts.json` пусты. Даже назначения разных экранов получили разные физические клавиши, поэтому неоднозначность контекста не скрывает конфликт.

Как и любой статический анализ, сканер может пропустить имя, собранное модом во время выполнения. После обновления модов нужен свежий снимок инстанса; один только набор строк локализации не подтверждает регистрацию клавиши. Сканер печатает покрытие снимка, а `seen` в реестре отличает действующие клавиши от оставшихся только в configureddefaults.

## Основные решения

- Ванильные движение, бой, инвентарь, быстрые слоты, чат, F2, F5, F11, L и вторая рука сохранены. Сняты только творческая загрузка/сохранение панели (C/X) и социальный экран (P), доступный из меню паузы. Освободившиеся кнопки отданы повседневным действиям сборки.
- TFC получает V для установки блока, C для смены режима долота и I для объединения еды. На V/I остаются исходные привычные клавиши; C находится рядом с движением и освобождает M карте.
- У всех открываемых меню есть отдельная клавиша: переносное хранилище, Curios, квесты, карта, инструменты Create/Sable, транспорт и полёт. Назначения инженерных механизмов не прячутся за разными вариантами R/G/V.
- JEI сохраняет R/U, назад Backspace и PgUp/PgDn. Закладка переносится с A на Y. Дополнительные мышиные псевдонимы, читерские и редакторские комбинации сняты; основные рецепты, применение и закладки доступны с клавиатуры, экраны управляются мышью.
- JourneyMap — единственная карта с клавишами зума; дубли FTB Chunks сняты, его карта и управление чанками доступны кнопками в инвентаре. Бинды панорамирования JourneyMap сняты: карту можно двигать мышью.
- Правые Shift/Ctrl/Alt отданы подсказкам Create, левый Alt подробностям Jade; эти клавиши не разделяются с другими действиями. Разблокировка IME перенесена с правого Shift на F12.
- Редактор квестов, редакторы ресурсных замен/музыкальных зон, отладка библиотек и служебные клавиши не занимают повседневную раскладку. Остальные снятые настройки доступны в соответствующих экранах или могут быть назначены игроком вручную.

## Обновление и проверка

```powershell
# После изменения модов обновите configureddefaults/options.txt свежим
# снимком регистрации или передайте путь нового инстанса прямо в --options.
python -B tools/keybinds/scan_keys.py --options configureddefaults/options.txt
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/build_preset.py --check
python -B tools/keybinds/check_preset.py --report
```

Править нужно словари `VANILLA`/`LAYOUT` генератора, затем пересоздавать файл. Не редактируйте 213 строк вручную. Снятые назначения остаются в файле как `key.keyboard.unknown` и не наследуют конфликтные значения пользователя.

Если файл пресета существует, CI заново читает jar и переносимый снимок, проверяет соответствие реестра, воспроизводимость генератора и конфликты **до** генерации манифеста и публикации `pack-latest`. Если пресет намеренно удалён, проверка пропускается и генератор не запускается, поэтому публикация не восстанавливает удалённый файл. Публикация включает `launcher/` в небольшой отдельный asset, поэтому обновлять EXE лаунчера для дальнейшего редактирования раскладки не нужно.
