# Управление TerraFirma Rebirth 1.0.0

Пресет подготовлен для полного авторского состава Minecraft 1.21.1 / NeoForge 21.1.248: 222 основных JAR из официального архива 1.21.1-1.0.0-release. Авторские моды, конфиги, косметика и шейдеры этим пресетом не удаляются и не переписываются. Он содержит только назначения клавиш; язык, графика и другие личные параметры сохраняются.

Лаунчер применяет его по отдельной кнопке управления. После применения назначения можно изменить обычным меню Minecraft.

## Основные клавиши

W/A/S/D, пробел, Shift, Ctrl, E, F, Q, 1–9, T, Tab, /, F2, F5, F11 и L сохраняют обычные роли. V ставит предмет TFC, C меняет режим долота, I складывает еду. B открывает рюкзак, X меняет инструмент, J выполняет действие рюкзака в инвентаре; G открывает Curios. H взаимодействует с повозкой, Z включает её медленный ход.

R/U показывают рецепты/применения JEI, Y добавляет закладку. M открывает карту, N создаёт точку, +/− меняют масштаб. Ё / grave accent открывает квесты. K переключает шейдеры, O открывает их выбор, F6 перезагружает их. Эти клавиши сами по себе не меняют исходные настройки качества.

## Добавленные действия полного авторского состава

| Действие | Клавиша |
| --- | --- |
| Kaleidoscope Contraption: удалить блок | Стрелка влево |
| Aeronautics Curios: действие пульта | Enter |
| Copycats: заполнить Copycat | F8 |

Освобождена только прежняя необязательная клавиша центрального экрана ModernUI на F8. Её строка теперь явно не назначена; при необходимости можно выбрать собственную кнопку в управлении. Прежние F10 для просмотрщика генерации TFC и F12 для IME сохранены, как и остальные старые назначения. Глобальные клавиши ОС, цифровой блок и дополнительные сочетания Ctrl/Shift/Alt не добавлялись.

Два переключателя Schematician оставлены без клавиши, как в авторском options.txt. Прямое открытие настроек Gnetum и Liubai также оставлено свободным, чтобы они не пересекались с управлением полётом и достижениями. Удалена устаревшая строка Entity Culling, отсутствующая и в новом авторском options.txt, и в новом сканировании JAR.

## Проверки и ограничения

В фактическом техническом клиенте нативный общий реестр содержит **223 имени**, а массив сохраняемых Options — **216**. Пресет теперь содержит ровно эти **216 имён**, без дополнительных языковых вариантов. Все 216 назначений совпали с фактическими нативными значениями главного меню до этой правки. Сохранены все **88 назначенных действий и 88 физических клавиш**; 128 строк остаются свободными.

Из прежних 221 строки удалены пять, причём все пять ранее были сняты. Две строки Friendship и `key.oelib.open_fluid_example` не зарегистрированы в актуальном клиенте. `key.jei.internal.enter.key` и `key.aero_cam_sync.add_mainhand_item_client` есть только во внутреннем общем реестре, но отсутствуют в Options. Исключение этих строк из файла пресета не отключает внутренние механизмы модов. Остальные пять внутренних записей общего реестра и раньше не входили в пресет.

Авторский архив по-прежнему содержит 219 строк options; историческая проверка их принадлежности хранится в `stock-owner-audit.json`. Это источник происхождения, а не текущий список сохраняемых клавиш. Исходные авторские options и 222 JAR не изменены. Генератор воспроизводит текущие 216 строк, а checker проходит без разрешённых конфликтных пар. Прежние проверки настоящих InputConstants/KeyMapping NeoForge 21.1.248 под Java 21 включали все эти клавиши как подмножество 221 строки и 3 828 пар неизменённых 88 назначений; отдельно были сопоставлены 5 184 пары контекстов/модификаторов. Штатный парсер/Apply/Evaluate лаунчера ранее прошёл девять проверок сохранности личных параметров и повторного применения.

Нативный реестр и совпадение 216 сохраняемых назначений уже измерены владельцем отдельного технического клиента; его SHA256 и точные исключения записаны в `preset-provenance.json`. Эта правка удаляет только пять несохраняемых снятых строк, поэтому не меняет ни одного измеренного назначения. Новый запуск игры или проверка сохранения после перезапуска ради этой сверки не выполнялись. Авторский options.txt не используется для копирования языка, графики или личных предпочтений в пресет.

## Проверка перед публикацией

CI проверяет `native-registry.json`: это очищенный список нативных Options и внутренних ALL-only имён с хешем исходного технического измерения. Он привязан к точным байтам текущих JAR, описания платформы и обоих авторских options-файлов. SHA256 самого списка закреплён в `preset-provenance.json`. Личные пути, игроки, UUID и необработанные логи в него не входят.

Публикационный шаг выполняет:

```text
python -B tools/keybinds/validate_native_registry.py
python -B -m unittest discover -s tools/keybinds -p "test_native_registry.py" -v
python -B tools/keybinds/build_preset.py --check
python -B tools/keybinds/check_preset.py
```

`scan_keys.py` остаётся инструментом поиска деклараций. Он не заменяет нативный Options и не перезаписывает публикационный реестр из устаревших строк авторского файла. При изменении JAR, платформы или исходных options валидатор остановит публикацию: нужно заново получить технический нативный реестр, проверить изменения и согласованно обновить список и его хеши. Число 216 относится к этому измерению; в коде валидатора не закреплено постоянное число модов или клавиш.
